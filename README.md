# Projeto_ML_motores
Pipeline de machine learning para diagnóstico de danos em rolamentos com corrente do motor (MCS) e vibração (dataset Paderborn). Reproduz e estende Lessmeier et al. (PHME 2016) com validação por rolamento, features de envelope e 7 algoritmos + ensemble. Vibração: 73–77% em 3 classes; detecção de dano: 87,7% de acurácia balanceada.
